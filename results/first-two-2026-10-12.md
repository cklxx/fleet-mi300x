# F and K implementation — 2026-10-12

Implemented both experiments; both remain **off by default**. No GPU session was run and no speedup is claimed. The recorded baseline remains v0.18, 3.593 / 3.595 / 3.596 ms/token, 32/32 tokens and 27/27 layers (`docs/STATUS.md:80`). Local results below establish implementation/build checks, not renewed hardware measurements.

**Switches and implementation.** Generate graphs with `--local-fold` (F) or `--local-kva` (K), always `--kv-chunks 16` for the shipped configuration. Compile **both** HIP translation units with the corresponding `-DFLEET_LOCAL_FOLD=1` / `-DFLEET_LOCAL_KVA=1`. Graph defaults are False; compiler defaults are 0. The additional `FLEET_VERIFY_LOCAL_ASSEMBLY=1` switch is a diagnostic, excluded from timing. Definitions: `src/host/taskgraph.py:905`, `src/host/taskgraph.py:956`, `src/kernels/local_assembly.h:5`.

- **F:** eight concurrent assemblers, pinned to worker 0 on each XCD, acquire the existing global producer event, execute the original ordered fp32-o_proj or bf16-expert fold, and publish one private 2,048-float vector per XCD through a count-one local event. Consumers stage that vector and run their existing norms. This covers 27 o_proj folds and 26 expert folds, including final lm_head: 424 added descriptors. The original fold functions, sum order, two bf16 boundaries and canonical residual publication remain intact. Only XCD 0 writes the other residual buffer; final lm_head writes neither. Private copies occupy a separate 64-KiB tail of x_norm. (`src/kernels/fleet_kernel.hip:107`, `src/kernels/fleet_kernel.hip:146`, `src/kernels/fleet_kernel.hip:605`, `src/kernels/fleet_kernel.hip:711`, `src/kernels/fleet_kernel.hip:905`; `src/host/fleet_launch.hip:615`; `src/host/taskgraph.py:790`; `tests/test_local_assembly_graph.py:125`.)
- **Lifetime:** unchanged global qkv/o_proj/down boundaries precede scratch reuse and publish canonical residual writes before remote consumers need them. The dependency test checks every old reader before overwrite, including token endpoints; original worker assignments and global event tables remain unchanged. (`tests/test_local_assembly_graph.py:76`, `tests/test_local_assembly_graph.py:119`, `tests/test_local_assembly_graph.py:143`.)
- **Difference from the losing global last-writer fold:** no globally last producer performs assembly for all eight XCDs, no additional global publication rendezvous, and readers consume a copy stored on their own XCD. There is still an added *local* assembly/publication/wait/stage tail; the old ~4-us loss is adverse evidence, not a promised saving. Reject F if that complete reader-ready interval is not shorter. The 259.7-us inventory is a gross historical pool, not predicted recovery. (`docs/STATUS.md:67`; `results/lever-space-2026-10-12.md:14`, `results/lever-space-2026-10-12.md:57`; `src/host/taskgraph.py:752`.)
- **K:** the projection remains one 576-row result, 72 rows produced per XCD. After its original global acquire, a workgroup physically resident on each consuming XCD gathers **all 576 floats** and stores them into its own slot; slot 0 remains the source and slots 1–8 are separate destinations, including XCD 0. This creates ownership through consumer-XCD stores, not merely eight addresses. Allocation grows by 2,304 bytes; 216 gather descriptors are added. (`src/kernels/fleet_kernel.hip:624`, `src/kernels/fleet_kernel.hip:729`, `src/kernels/fleet_kernel.hip:749`; `src/host/fleet_launch.hip:625`; `tests/test_local_assembly_graph.py:125`.)
- **K's cost and overlap:** charge 2,304 bytes read + 2,304 bytes written per XCD/layer, or 36,864 bytes/layer and 995,328 bytes/token, plus local readiness and the existing 256 consumers' 589,824 bytes/layer of reads. These are logical requests, not measured HBM traffic. The gather uses exactly the remaining worker, 37−32−4=1; all q_c publisher assignments, original global waits, and the attention consumer's later PUB_WAIT/acquire remain. Gathering can run alongside q_c publication, but attention must wait for the gather before kv_post. The recorded +2-us penalty supplies only K's 54-us gross envelope; copying must earn back its own cost. (`src/host/taskgraph.py:774`; `src/kernels/fleet_kernel.hip:632`, `src/kernels/fleet_kernel.hip:772`; `tests/test_local_assembly_graph.py:145`; `docs/STATUS.md:76`; `results/lever-space-2026-10-12.md:19`.)

F rejects row-split o_proj or replicated kv_a. K requires 16 heads, 16 chunks, shared kv_a and q_c publication. Feature launches reject coherent-acts/prefetch-next. Use matching feature binaries and graphs: the byte-preserved all-off executable retains its old descriptor handling and cannot diagnose these new flags. The GPU runner builds the matching pairs and checks feature/proof banners. (`src/host/taskgraph.py:765`; `src/host/fleet_launch.hip:412`; `tests/run_local_assembly_gpu.py:120`, `tests/run_local_assembly_gpu.py:137`.)
